# 车道契约和共享资源

触发：任务交给多个执行者，或准备检查依赖与并行冲突。

派工说明包含目标范围、输入定位、输出形状、已决定/待决定事项、验收、可写资源与停止条件。明确执行者不是独自在工作区，不回滚其他人的改动。交接只传接手所需的证据、当前状态和未决项，不复制所有上下文。撤回或取消按相关车道身份定向处理，保护其他进行中工作。

独立查资料可并行；三人修改同一清单由单owner整合，或加完成依赖。若共享上下文很强、依赖链长、任务很小，单执行者或顺序流程通常更适合。

可选只读检查：`python3 scripts/check_plan.py plan.json`（从本Skill目录运行）。输入：`{"tasks":[{"id":"research","depends_on":[],"writes":["notes"]},{"id":"merge","depends_on":["research"],"writes":["notes"]}]}`。写资源名应规范统一；目录/文件重叠须用共同资源名，不做自动路径推断。

退出0只证明给定图无环、依赖完整、同名写资源有先后；退出2表示结构或冲突错误。JSON输出ready/顺序建议，不执行任务，也不证明语义独立、成本收益或授权。遗漏/别名资源仍需审阅者检查。

依据：[多Agent研究的适用与成本](https://www.anthropic.com/engineering/multi-agent-research-system)。
