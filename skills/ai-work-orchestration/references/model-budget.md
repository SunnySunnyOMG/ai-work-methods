# 基线、成本与筛查偏差

触发：准备降级模型、大批筛查或加速多执行者工作。

先定义可接受漏检/误判、实际输出判据，取得少量可靠参考判断；便宜模型与之对照，足够才扩量。保留常见、边界、反例和随机低优先级样本，不只精读高分候选。输入标签只证明导航判断。抽中样本要回源阅读所选原材料；历史任务要读完整任务窗口及必要执行/接收结果证据。不能只让强模型重判相同标签，再当结果验证。

记录请求/实际可确认模型、调用量、usage、延迟、失败和未决队列；usage未返回就标未知，不当零成本。并行度受限于资源、失败率和整合劳动，先小批观察再调整。对重复错误有限重试；覆盖分母不因失败偷偷缩水。

十个相同文本可以复用主题判断，但角色、授权、来源分支与结果不能跨会话继承。抽样结果是局部质量信号，不能声称全量语义已被验证。

依据：[先建立基线再优化模型](https://openai.com/business/guides-and-resources/a-practical-guide-to-building-ai-agents/)、[普通/边界/对抗评测](https://developers.openai.com/api/docs/guides/evaluation-best-practices)。
