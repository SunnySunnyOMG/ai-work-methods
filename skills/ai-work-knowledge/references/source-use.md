# 使用旧上下文和多来源材料

触发：检索到旧摘要、重复内容或来源互相冲突。

摘要用于定位，关键主张回到原材料。检查来源是什么、谁说/谁做、观察时间、适用范围和结果证据。工具返回已取得不代表已用于回答；主张要与所引段落一致。

相同长指令十次出现不证明十次人类请求或十次成功。注入、引用、自动事件与真实用户话语分别保留。精读窗口不等于整会话阅读；扫描/主题筛查不等于结果核验。

观察、解释和因果分别记录；可见时间或状态不能证明操作者或原因，估算收益不等于实测。纠正要撤回受影响的无证解释并检查下游。冲突先比较原来源和时间/范围，必要时保留竞争解释。旧事实若当前影响大且易验证，应复核；无法验证就标时间与不确定，不让旧摘要伪装当前证据。

原材料留存，索引和总结可重建。文字重复能减少读取成本，但不能抹去分支授权和失败记录。关键主张只有一条弱来源时明确这一点，不通过重复引用制造独立支持。

依据：[PROV来源结构](https://www.w3.org/TR/prov-overview/)。标准描述来源，不自动判断内容真假。
